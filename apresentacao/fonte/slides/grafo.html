O context graph liga atividade, característica operacional, risco e dimensão de proteção. Treinamos os priors na base de desenvolvimento: para cada subclasse CNAE contamos quantas empresas têm cada característica, com peso cheio para dado observado e peso 0,3 para derivado ou estimado, e quando a subclasse tem poucos dados recuamos para a divisão. Quando a probabilidade passa de 0,8 e o caso não tem o fato, o grafo gera uma hipótese, que nunca é tratada como verdade: ela vira pergunta. A força de cada necessidade é a probabilidade vezes o peso da exposição. O grafo é versionado; fatos confirmados na jornada podem gerar uma nova versão.
